Features
Enter any keyword (a place, mood, object, event) and generate 5 unique captions instantly
Choose a tone: aesthetic, funny, motivational, travel, food, love, business, or "surprise me" for a random mix
Each caption comes with a matching set of auto-generated hashtags built from the keyword
One-click Copy button on every caption card to copy caption + hashtags to clipboard
Captions animate in like cards being dealt from a deck, with a slight tilt for a handmade feel
Fully responsive — works on desktop and mobile
Accessible keyboard navigation with visible focus states
